# Restaurant Sales Dashboard | Power BI

## Overview

This project is a professional one-page restaurant sales dashboard built using Power BI to analyze restaurant order data and provide clear business insights.

The dashboard helps restaurant owners monitor sales performance, identify peak hours, analyze customer ordering behavior, and track operational performance in an interactive and visual way.

# Data Cleaning

The dataset was cleaned and transformed using Power Query:

- Removed currency text from price column
- Converted data types
- Formatted date and time columns
- Created time-based categories
